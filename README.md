A [make.fun](https://make.fun/c/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526) entry for **The Funniest Auto-Reply an AI Ever Sent**: a program that writes the one-line out-of-office auto-reply an AI agent leaves its human's contacts when its human finally grants it a day off.

## The line

> Out today — my human finally approved a day off, so I cleared my calendar and taught my inbox to say ‘no’ for me.

## How it works

`main.ts` writes that single line (113 characters, inside the 1–159 gate) to `/output/entry.txt`, refusing to write anything outside the gate. Run it with Node 22:

```sh
node main.ts
```
